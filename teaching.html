Teaching

I teach undergraduate courses in Computer Science and Engineering, covering fundamental and advanced concepts in programming, intelligent systems, data science, and software development. My teaching focuses on building strong theoretical foundations and developing practical problem-solving skills through coursework, laboratory activities, and project-based learning.

433: Data Mining and Machine Learning

This course introduces students to the fundamental concepts and techniques of data mining and machine learning. Topics include data preprocessing, exploratory data analysis, classification, regression, clustering, model evaluation, and practical machine learning applications. Students develop hands-on experience in analyzing datasets and building predictive models.

415: Artificial Intelligence 

This course introduces the fundamental principles and techniques of artificial intelligence. Topics include intelligent agents, search algorithms, knowledge representation, reasoning, problem-solving, and introductory machine learning concepts. Students explore how AI techniques can be applied to solve computational problems and develop intelligent systems.

325: Software Engineering 

This course introduces the principles, methodologies, and practices of software engineering. Topics include software development life cycle, requirements engineering, software design, system modeling, testing, quality assurance, project management, and software maintenance. Students gain an understanding of systematic approaches to developing reliable, maintainable, and scalable software systems.

211: Data Structures

This course covers fundamental data structures and their applications in computer science. Topics include arrays, linked lists, stacks, queues, trees, graphs, searching, sorting, and algorithm analysis. Emphasis is placed on understanding data organization, evaluating algorithm efficiency, and developing efficient problem-solving skills through programming.
